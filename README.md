# Smart City Cameroon & GreenTech 🌿

Une plateforme web moderne dédiée aux solutions écologiques et technologiques pour les communautés au Cameroun. Ce projet met en avant des réalisations concrètes en matière d'énergie solaire, d'agriculture intelligente et de villes connectées.

## 🚀 Fonctionnalités
- **Design Responsive** : Entièrement optimisé pour les smartphones, tablettes et ordinateurs.
- **Section Projets** : Une grille uniforme affichant nos réalisations concrètes avec un impact réel.
- **Animations Fluides** : Effets au survol sur la navigation et boutons directionnels interactifs.

## 🛠️ Technologies utilisées
- **HTML5** : Structure sémantique de la page.
- **CSS3** : Mise en page moderne (Flexbox, variables CSS, Media Queries).
- **Fonts** : Montserrat (via Google Fonts).

## 📂 Structure du projet
```text
projet-01-greentech/
├── assets/
│   └── images/          # Contient les images (heroimage.png, p-1.jpeg, p-2.jpeg)
├── index.html           # Structure principale de la landing page
├── style.css            # Styles et responsive design
└── README.md            # Documentation du projet
```

## 💻 Installation locale

Pour lancer le projet sur votre machine :

1. **Cloner le dépôt** :
   ```bash
   git clone https://github.com
   ```
2. **Accéder au dossier** :
   ```bash
   cd projet-01-greentech
   ```
3. **Ouvrir le projet** :
   Ouvrez le fichier `index.html` directement dans votre navigateur ou utilisez l'extension **Live Server** sur VS Code.
